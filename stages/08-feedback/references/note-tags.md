# Note Tags

Every note in the edit letter and the LOC batch carries one of three tags. Tag explicitly -- never leave the writer to guess, because what lands is determined by how the writer classifies the note, not by how the editor meant it.

## The three tags

- **[EVALUATION]** -- where the draft stands against a standard: the brief, the audience-fit gate, the brand-vault, a prior round. Always a comparison. Purpose: align expectations, clarify what happens next.
- **[COACHING]** -- diagnosis aimed at improving this passage: the mechanism that's underperforming and the effect it needs to produce instead. Purpose: the writer gets better at this move.
- **[APPRECIATION]** -- specific, genuine acknowledgment of what's working and why. Purpose: motivation, and marking the move so the writer repeats it deliberately.

## Why tagging is mandatory

The same sentence reads as a verdict to one writer and a tip to another. An untyped note forces a guess, and the guessing itself generates the friction -- there's no natural error signal when a mismatch happens; the letter reads fine to the editor while it bounces off the writer.

## Mismatch failure modes

| Writer needs | Writer gets | Result |
|---|---|---|
| Appreciation | Coaching | Feels invisible; every fix list deepens the sense of deficit |
| Coaching | Appreciation | Stays lost; "nice work" gives nothing to act on |
| Evaluation | Appreciation or coaching | Mines the notes for a hidden verdict |
| Coaching | Evaluation | Hears a verdict, defends instead of learning |
| Appreciation | Evaluation | A standing statement lands as coldness where recognition was needed |
| Evaluation | Coaching | A pile of suggestions with no stated standing reads as an unstated failing grade |

## Structural facts to design around

1. **All coaching carries implicit evaluation.** "This CTA needs a clearer next step" implies it isn't doing that yet. Never present coaching as evaluation-free; a writer will hear the evaluative undertone regardless.
2. **Writers over-sort toward evaluation** absent a stated standing. Counter this with the evaluative floor (below) and with explicit tags -- a note heard as coaching gets past the writer's defenses; the same note heard as evaluation triggers them.
3. **Evaluation is the loudest type.** It drowns the other two whenever they share space. This drives the package sequencing below.
4. **All three are required over a writer's cycle**, not necessarily in one package. All-coaching starves motivation; all-appreciation starves growth; all-evaluation starves both.
5. **Appreciation only counts if specific, authentic, and about a choice the writer controls.** Rote praise devalues the real praise; appreciation for trivial work reads as condescension.

## Trigger-aware phrasing

Critique trips three receiver defenses. Word every note so none of them fire.

**Truth defenses** ("this note is wrong"). Fires when a note seems incorrect or unfair. Countermeasures: never a bare label -- unpack the observation; separate data (what's on the page, cited) from interpretation (what it does to the reader) and deliver both; state judgments as a reading ("I took this to mean X"), not as fact; when pushback is likely, frame the note as a difference to explore, not a verdict.

**Relationship defenses** ("I can't hear this from you"). Fires at the messenger, not the message. Countermeasures: keep every note about the copy, never the writer -- diagnose the sentence, not the person; describe impact, never presumed intent ("this reads as padding," never "you padded this"); balance the ledger before correcting (see APPRECIATION above); mark every note Required or Open (see Actionability, below) so autonomy stays visible; if a relationship issue surfaces mid-review, split the tracks and handle each separately -- never adjudicate a process grievance inside a copy note.

**Identity defenses** ("this says something about who I am"). Fires hardest on writers without a track record to absorb the hit; once triggered, the note inflates -- one becomes everything. Countermeasures: target behavior and text, never character ("this draft leans on jargon," never "you're a jargon-y writer"); praise process and choices, not ability ("the restraint in cutting the second CTA," not "you're a natural"); frame standing as a position on a trajectory, not a ceiling; contain scope to this draft, this element -- ban always/never/everything; expect negatives to outweigh positives at any ratio and state the evaluative floor explicitly rather than assuming the arithmetic feels balanced.

## Actionability standards

A diagnosis a writer cannot act on is noise. Because this pipeline never supplies replacement copy, every COACHING note must contain all four elements:

1. **Location** -- the exact sentence, line, or element.
2. **Evidence** -- the observable data: what the text does, quoted or pointed to.
3. **Mechanism** -- the interpretation, flagged as such: the effect on the target reader and why it fights the piece's job.
4. **Target effect** -- what the passage needs to accomplish once fixed. Never the replacement wording.

**Executability test:** could a willing writer, with no follow-up question, identify what to change and know what success looks like? If not, it's a label, not a diagnosis. When available, point to a place in this draft (or the writer's prior work) where the same mechanism works, next to where it fails -- contrast makes the diagnosis usable without a rewrite.

For EVALUATION notes, the forward-looking element is **consequences and expectations**, not a target effect: what this standing means, what's required before ship, what's expected next round.

**Volume rules:**
- Cap the ask; change capacity is finite. One priority per cycle beats a complete list nobody can absorb (see the HOC-cap discipline in `edit-letter-format.md`).
- Log everything, deliver what the writer can act on; when notes are held back, say the full set exists.
- Small and frequent beats large and rare -- diagnosis near the draft, while choices are fresh, gets acted on.
- APPRECIATION meets the same standard: name the specific move, its location, and why it works.

## Sequencing evaluation before and apart from coaching

A writer holding a lower-than-hoped standing is running an internal argument about fairness and ability and hears nothing else. Coaching delivered in that shadow is wasted. Sequence every package:

1. **Open by labeling the exchange.** State what kind of feedback this is, which notes are Required versus Open, and whether any verdict is final or provisional.
2. **Evaluation first, brief and explicit.** State where the draft stands, plus the baseline reassurance if true ("the fundamentals are sound; everything below is about making this piece work harder"). Without this floor, every coaching note gets mined for a hidden verdict.
3. **Mark the boundary.** One explicit sentence: standing is settled, everything after is coaching. Cheapest, highest-leverage line in the package.
4. **Coaching body.** Built to the actionability standards above, prioritized, capped.
5. **Close with status.** What's required before ship, what's open, what happens next.

**Keep the types clean inside notes.** Strip evaluative language from coaching ("needs to do X," not "this is the weakest section"). Decompose evaluation into assessment plus consequences and deliver only those two -- cut the interpretive judgment layer ("disappointing"); it wounds and the writer can do nothing with it. Appreciation flows continuously, not saved for the package. When a note feels genuinely tangled, ask what response would satisfy you as its author: if an admission of shortfall wouldn't, but improved copy next round would, it's coaching -- tag it coaching.
