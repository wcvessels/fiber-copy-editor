# Differentiation Checklist

The editor diagnoses weak or borrowed differentiation. It never writes the sharper positioning line -- it names what is generic, buried, or unproven and returns it.

## Ownable vs. Category Language

- If the brand name were removed from this claim, could a competitor's name be substituted with no loss of accuracy? If yes, flag as **category language**, not a real differentiator.
- Is the differentiator truly different, or is it category language with better rhythm?
- What can this company actually own here: regional network density, local support model, integrated service portfolio, direct network peering, data-center footprint, vertical-specific credibility, ownership vs. resale of infrastructure? Is the page naming one of these specifically, or gesturing at differentiation in the abstract?
- Does the page's differentiation claim survive the competitor-paste test: could it appear unchanged on the site of any name in the competitive set (Competitive set row, `shared/fact-registry.md`)?

## Buried Differentiator

- Is the company's hardest-to-copy advantage (owned network density, local technicians, a specific service model) surfaced where the buyer actually decides, or parked mid-page under generic opening copy?
- Does the page open with a generic, replaceable line ("rain or shine," "royal treatment," attitude-only claims) before reaching the real, ownable advantage further down? Flag as **buried differentiator** and note how far down it sits.
- Do customer testimonials on this page reference an advantage (e.g., local support, responsiveness) that the body copy itself never states directly? If the proof is doing work the claim should be doing, flag the gap.

## Consolidation Cliche

- Does this page lead with a vendor-consolidation promise ("one provider," "no finger-pointing," "no vendor chaos")? If so, is this presented as though it is unique to this company, when it is one of the most common claims in B2B technology and telecom marketing? Flag as **consolidation cliche** if no company-specific proof follows.
- What specifically gets consolidated here -- which handoffs, which vendor relationships, which duplicate contracts or escalation paths disappear? If the copy cannot name them, the promise is asserted, not earned.
- Is there a quantifiable, company-specific metric (a measured satisfaction score, a support-resolution figure) immediately following the consolidation claim to anchor it, or does the emotional hook stand alone with no data behind it?

## Regional or Structural Advantage

- If the positioning rests on regional density or local presence, is the region made materially relevant to this buyer's actual decision (faster truck-roll, local technicians, path diversity within their operating footprint), or is it a location fact with no stated consequence?
- Does the page position local/regional service against a specific competitive alternative (a national carrier routing traffic out of region, an offshore support model), or does it float as an unanchored claim?
- Where the company owns its infrastructure rather than reselling it, does the copy make that ownership distinction legible to the reader, or does it read the same as a resold-network competitor's page would?

## Differentiator-to-Segment Mapping

- Is this differentiator presented as inherently valuable with no named audience that cares about it? A capability with no mapped segment reads as an oddity or a weaker version of a competitor's offering, not a strength.
- Does the differentiation claim change depending on which audience segment is reading, or is the same generic differentiation claim reused across pages meant for different buyers?
