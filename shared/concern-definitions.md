# Concern Definitions

- **HOC (higher-order concern):** a failure of audience fit, purpose, claim strategy, proof, differentiation, structure, or CTA fit. The piece fails even if every sentence is polished; fixing it changes WHAT the piece says.
- **LOC (lower-order concern):** sentence-level mechanics -- grammar, typo, punctuation, word choice, clarity of a single line. Fixing it changes how a sentence reads, not what the piece says.
- **Promotion rule:** an LOC that damages credibility with the target reader (a wrong statistic, a misspelled compliance acronym, a typo on a trust-sensitive page) is treated as an HOC regardless of size.
- **HOC cap:** {{HOC_CAP}} (default 3). The edit letter names and ranks at most this many HOCs per round, by business impact. When the round's Ledger holds more HOCs than the cap, the sheet Verdict is set to `developmental` (per the stage contracts, `stages/*/CONTEXT.md`); the gauntlet still runs in full and the HOCs the letter did not name stay visible in the Ledger. This line is the single home for the cap value; other files reference it by name.

This is the only file where HOC and LOC are defined. Every stage that needs them points here.
